# 📱 Dovely Admin (Beta Test Build)

**Dovely Admin** is a lightweight, offline-first mobile administration and management application designed for local service businesses, contractors, and solo managers. 

This repository serves as an open testing hub for earlier beta releases. We are gathering user feedback to help shape the next version, which is being built completely from scratch.

---

## ✨ Key Features in This Test Build

- **Invoicing & Client Records:** Create, manage, and review client invoices locally on your device.
- **Daily Operations Dashboard:** Clean interface for tracking core administrative tasks and business activity.
- **Weather Service Integration:** Built-in weather checks to help contractors and field workers schedule outdoor jobs.
- **Offline-First Storage:** Runs locally on your device without requiring an active cloud account or external server setup.

---

## 📥 How to Download & Install

1. Navigate to the **[Releases](../../releases)** section on the right side of this repository.
2. Under the latest version (`v2.0.1`), expand **Assets**.
3. Tap the `.apk` file (e.g., `Dovely_Admin_v2.0.1.apk`) to download it directly to your Android device.
4. Open the downloaded file on your phone or tablet to install it.
   > *Note: Since this is a test build, your device may ask you to enable "Install from Unknown Sources" or allow your browser to install unknown apps.*
